# 💫 About Me:
Soy desarrollador Full-Stack con un enfoque principal en Frontend, apasionado por crear interfaces modernas, intuitivas y eficientes que ofrezcan una excelente experiencia de usuario. Me especializo en el desarrollo de aplicaciones web utilizando tecnologías como JavaScript, React, Expo y Laravel, integrando de manera sólida el frontend con APIs y servicios backend. Disfruto transformar ideas en productos funcionales, optimizando el rendimiento, la usabilidad y la escalabilidad de cada proyecto. Constantemente estoy aprendiendo nuevas herramientas y mejores prácticas para construir aplicaciones más robustas y mantenibles.
