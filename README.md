## 💫 About Me

I'm a **Backend Python Developer** with a **Mechatronics Engineering** background. I build APIs with **FastAPI, SQLAlchemy and PostgreSQL**, test them with **pytest** and ship them with **Docker and GitHub Actions**.

Before software, I worked as a **maintenance technician** with **PLCs and sensors** on the plant floor. That's the direction I'm heading: connecting the machines that generate data with the systems that process it, in **Industrial IoT and Industry 4.0**.

I'm also an **entrepreneur**, and I want to build software for real businesses, with real users and real constraints. I care about clean architecture, testing, and understanding how things work under the hood — not just making them work.
