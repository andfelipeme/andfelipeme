## 💫 Sobre mí

Soy **desarrollador backend en Python** con formación en **Ingeniería Mecatrónica**. Construyo APIs con **FastAPI, SQLAlchemy y PostgreSQL**, las pruebo con **pytest** y las despliego con **Docker y GitHub Actions**.

Antes del software trabajé como **técnico de mantenimiento** con **PLCs y sensores** en planta. Hacia allá voy: conectar las máquinas que generan los datos con los sistemas que los procesan, en **IoT industrial e Industria 4.0**.

También soy **emprendedor** y quiero construir software para negocios reales, con usuarios y necesidades reales. Me importan la arquitectura limpia, las pruebas y entender cómo funcionan las cosas por dentro, no solo hacer que funcionen.
